# Claude Code project guidance

Art direction is detailed stylized realism, not low-poly. Follow ART-DIRECTION.md and reuse the shared manufactured scooter and weighted clothing pipeline. The latest owner rule requires a specific request and fresh affirmative confirmation before any GitHub push. Public updates to the existing Sites game remain authorized after testing.

Read and follow [AGENTS.md](AGENTS.md), [DEVELOPMENT.md](DEVELOPMENT.md), and [SYSTEMS.md](SYSTEMS.md) before editing. Use your own clone/worktree and task branch. Never edit the same checkout concurrently with Codex. Preserve riding controls and physics unless explicitly targeted. Test and build before proposing a merge. The repository is public (owner's choice, for GitHub Pages), so keep credentials out of Git. Every tested push to `main` auto-deploys to scootwithfriends.online (see DEPLOYMENT.md); other public game updates require the documented owner authorization, and there are no other automatic deployments or DNS changes.
