SCOOT WITH FRIENDS - WINDOWS EDITION

1. Extract the entire ZIP.
2. Double-click Play Scoot with Friends.cmd.
3. Leave its server window open while playing. Close it to stop.

The included runtime needs no install, account, or coding credits. Solo play
works offline. When connected, the game can load the latest published park.

PRO (regular stance): X pushes, A tailwhips, B barspins. Goofy swaps A and X.
RS down loads a hop; release pops. Circular RS sweeps can take off directly
into Bri / Inward Bri. Hold whip/bar buttons for continuous spins.
ARCADE: A hops, X pushes on ground / barspins in air, B tailwhips.
Select the control style in Settings. H shows the full controls.
LT brakes, RT pumps/grinds. Y walks or mounts. On foot A jumps/climbs,
B sits near benches, and LS click runs carrying the scooter.
After a crash, A gets up locally; recovery also happens automatically.
Keyboard: Space=A, X=X, B=B, Y=Y, arrows=RS, WASD=LS, Ctrl=LT,
C=RT, Shift=LB, E=RB, F=run, M=marker, R=reset, Esc=pause.

PARK EDITOR is on the main menu. Choose an asset, then click to place it.
G moves, T rotates, J resizes. Numeric fields and grid/angle snapping help.
Right drag orbits, middle drag pans, wheel zooms. WASD flies; Q/E moves up/down.
Controller: LS flies, RS looks, triggers move vertically.
Save / Save As stores named parks on this device. Export JSON backs up or
shares a design. Import JSON loads it. Undo/Redo retains 60 edits.
Terrain tools edit the surrounding grounds and protect the wooden park.
Draw Path adds points; Finish Path makes one curved route. Pick its width
and dirt, concrete, asphalt, or gravel surface. Test Ride uses that same park.
Return to Editor keeps your work.

This is a solo freestyle game. Multiplayer is not implemented.

PLAY ON PHONE (same Wi-Fi)
1. Double-click Play on Phone.cmd. Keep its window open.
2. If Windows asks, allow Node on your PRIVATE network.
3. Scan the code shown in the window (or on the page it opens) with the
   phone camera, or type the address it prints into the phone's browser.
4. Turn the phone sideways and tap Enable Game. Touch controls appear.
Only the game itself is shared on your home network; the owner tools and
your saves are not. Close the window to stop sharing. If the phone cannot
connect, check that it is on the same Wi-Fi and that the router does not
isolate wireless devices (guest networks often do).
